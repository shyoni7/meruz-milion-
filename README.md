# המירוץ ל-70 🏁

אפליקציית משחק מירוץ עצמאי לכבוד יום הולדת 70 — "המירוץ ל-70".
קבוצות משפחה משחקות יחד, עוברות תחנות, פותרות רמזים, מצלמות תמונות, ובסוף צופות במצגת כללית של כל הרגעים.

## ארכיטקטורה

| שכבה | טכנולוגיה |
|---|---|
| Frontend | React 19 + Tailwind CSS 4 + Framer Motion |
| Backend | Express 4 + tRPC 11 |
| DB | MySQL (PlanetScale / TiDB Cloud / Railway) |
| Storage | Cloudinary (תמונות שמועלות במשחק) |
| Auth (אדמין) | JWT + bcrypt |
| Routing | Wouter (client-side SPA) |
| Hosting | Vercel (Serverless) |

## זרימת המשחק — שחקנים

```
/ (GamePage)
  └── SplashScreen       — מסך פתיחה קולנועי עם לוגו "70"
        └── RegisterScreen — רישום קבוצה (שם + טלפון)
              └── [לכל תחנה]:
                    ├── ScratchScreen   — גרד כרטיס גרד לגילוי מספר התחנה
                    ├── ClueScreen      — הרמז לתחנה הבאה
                    ├── TaskScreen      — המשימה + כפתור Waze + מרכז רמזים + העלאת תמונה
                    ├── ControlRoom     — המתנה לאישור מצוות ההפקה
                    └── TaskComplete    — הצלחה! + עובדה מעניינת
                          (או TryAgain  — דחייה + ניסיון חוזר)
              └── FinishScreen  — סיום המירוץ + קישור למצגת הכללית
```

## מסכי המשחק

### SplashScreen — מסך פתיחה
- רקע קולנועי עם לוגו "70" זהוב
- כפתור "התחילו את המסע"

### RegisterScreen — רישום קבוצה
- שדות: שם הקבוצה + מספר טלפון
- שמירה ב-DB, teamId נשמר ב-localStorage

### ScratchScreen — כרטיס גרד
- כרטיס גרד אינטראקטיבי על Canvas
- שכבת כסף מתכתית עם טקסטורת רעש
- חשיפה אוטומטית ב-45% גרידה
- אפקטי שמע: גרידה (Web Audio API) + פנפרה הצלחה
- מספר התחנה מתגלה בהנפשה

### ClueScreen — מסך רמז
- רקע תמונה קולנועי + שכבת gradient
- כרטיס זכוכית עם טקסט הרמז
- badge מספר תחנה

### TaskScreen — מסך משימה
- הוראות המשימה
- כפתור Waze (אם הוגדר קישור לתחנה)
- כפתור "צריכים עזרה?" → פותח HintCenter
- העלאת תמונה מהמצלמה (capture="environment")
- תצוגה מקדימה של התמונה לפני שליחה

### HintCenter — מרכז רמזים
- Bottom sheet modal
- רמזים מתגלים אחד אחד (עד 3 רמזים לתחנה)
- כפתור "רמז ראשון" / "רמז נוסף"

### ControlRoom — חדר הבקרה
- מסך המתנה לאישור מצוות ההפקה
- הנחיה לבדוק WhatsApp
- שני כפתורים: "המשימה אושרה" / "התבקשנו לנסות שוב"
- גישה למרכז הרמזים

### TaskComplete — הצלחה
- חותמת APPROVED בהנפשה
- עובדה מעניינת על שלמה (מוגדרת לכל תחנה)
- קונפטי זהוב
- כפתור "המשך למשימה הבאה"

### TryAgain — נסו שוב
- הודעת דחייה
- כפתור "שלח תמונה חדשה" → חזרה לTaskScreen
- גישה למרכז הרמזים

### FinishScreen — סיום
- קונפטי זהוב ל-5 שניות
- הודעת "כל הכבוד! השלמתם את המירוץ ל-70"
- כפתור "צפו במצגת כל המשתתפים" → `/slideshow`

## ממשק ניהול — צוות הפקה

**כניסה:** `/admin` → שם משתמש + סיסמה (JWT, תוקף 24 שעות)

### לוח הבקרה (`/admin`)

**כרטיסי סטטיסטיקה (מתעדכנים כל 10 שניות):**
- מספר קבוצות רשומות
- מספר קבוצות שסיימו
- מספר תחנות פעילות
- מספר תמונות ממתינות לאישור

**כרטיסי ניווט:**
- ניהול תחנות
- קבוצות
- אישור תמונות (עם badge מספר ממתינות)
- הפעל מצגת כללית

**לוח מובילים בזמן אמת:**
- רשימת כל הקבוצות ממוינות לפי התקדמות
- progress bar לכל קבוצה
- badge "פעיל" / "סיים 🏆"
- מדליות 🥇🥈🥉 ל-3 הראשונים

### ניהול תחנות (`/admin/stations`)

**שדות לכל תחנה:**
- כותרת + כותרת משנה
- טקסט רמז + URL תמונת רמז (אופציונלי)
- כותרת משימה + תיאור משימה + URL תמונת משימה (אופציונלי)
- עד 3 רמזים
- קישור Waze (אופציונלי)
- עובדה מעניינת (מוצגת אחרי הצלחה)
- מצב פעיל/לא פעיל
- סדר תצוגה (orderIndex)

**פעולות:** הוסף תחנה חדשה / ערוך / מחק

### קבוצות (`/admin/teams`)
- רשימת כל הקבוצות: שם + טלפון + תחנה נוכחית + סטטוס
- מחיקת קבוצה (כולל כל התמונות שלה)
- כפתור מצגת כללית לכל שורה

### אישור תמונות (`/admin/submissions`)

**ממתינות לאישור:**
- תצוגת תמונה מלאה
- כפתורי אשר / דחה / מחק

**נסקרו:**
- גריד תמונות עם badge אושר/נדחה
- מחיקה בודדת

## מצגת כללית

**נתיב:** `/slideshow`

מצגת אוטומטית של **כל התמונות מכל הקבוצות**, ממוינות לפי סדר התחנות.

**תכונות:**
- ניגון אוטומטי כל 4 שניות
- badge תחנה (ימין, זהוב) + badge שם קבוצה (שמאל)
- כיתוב שנון בעברית (מופעל אם `OPENAI_API_KEY` מוגדר)
- כפתורי ניווט: הקודם / נגן-עצור / הבא
- נקודות התקדמות (לחיצה לדילוג לשקופית ספציפית)
- מצב ריק: הודעה "אין תמונות עדיין"
- מצב שגיאה: כפתור "נסה שוב"

## מסד הנתונים

### טבלאות

| טבלה | תיאור |
|---|---|
| `users` | משתמשי Manus OAuth (לא בשימוש פעיל) |
| `admin_users` | צוות הפקה (username + passwordHash + displayName) |
| `stations` | תחנות המשחק עם כל השדות |
| `teams` | קבוצות משתתפות (שם + טלפון + התקדמות) |
| `submissions` | תמונות שהועלו (imageUrl + status: pending/approved/rejected) |

### הרצת migration
```bash
pnpm db:push
```

## דיפלויימנט לוורסל

### שלב 1 — DB MySQL חינמי
בחרו אחת מהאפשרויות:
- [PlanetScale](https://planetscale.com) — מומלץ
- [TiDB Cloud Serverless](https://tidbcloud.com)
- [Railway](https://railway.app)

### שלב 2 — Cloudinary חינמי
הירשמו ב-[cloudinary.com](https://cloudinary.com) (25GB storage/month חינם).
העתיקו: Cloud Name, API Key, API Secret.

### שלב 3 — חיבור לוורסל
1. כנסו ל-[vercel.com](https://vercel.com) → **Add New Project**
2. בחרו את הריפו `shyoni7/meruz-milion-`
3. הגדירו את משתני הסביבה (ראו טבלה למטה)
4. לחצו **Deploy**

### שלב 4 — הרצת migration
לאחר הדיפלויימנט הראשון, הריצו:
```bash
pnpm db:push
```

## משתני סביבה

| משתנה | תיאור | חובה |
|---|---|---|
| `DATABASE_URL` | MySQL connection string | חובה |
| `JWT_SECRET` | מחרוזת אקראית 32+ תווים (`openssl rand -hex 32`) | חובה |
| `CLOUDINARY_CLOUD_NAME` | שם הענן ב-Cloudinary | חובה |
| `CLOUDINARY_API_KEY` | API Key של Cloudinary | חובה |
| `CLOUDINARY_API_SECRET` | API Secret של Cloudinary | חובה |
| `ADMIN_USERNAME` | שם משתמש האדמין (נוצר אוטומטית בהפעלה ראשונה) | חובה |
| `ADMIN_PASSWORD` | סיסמת האדמין | חובה |
| `ADMIN_DISPLAY_NAME` | שם תצוגה (ברירת מחדל: "צוות הפקה") | אופציונלי |
| `OPENAI_API_KEY` | מפתח OpenAI לכיתובים שנונים במצגת | אופציונלי |

> **הערה:** `ADMIN_USERNAME` ו-`ADMIN_PASSWORD` — בכל הפעלת שרת, אם המשתמש לא קיים ב-DB, הוא נוצר אוטומטית. בטוח לריצה חוזרת.
